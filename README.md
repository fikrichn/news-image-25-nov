One image that sums up the world's news of Wednesday, 25 November 2026: a
newspaper front page — "The World in One Day" — with seven dated stories
across regions and fields (Ukraine's drone strike on a Russian ship, the
Houthi missile on Riyadh's tallest tower, Shenzhou-24's launch, China's
probe into Chen Jining, Nvidia's Huang reinstated, the FBI's global scam
crackdown, Senegal's Africa Cup title) plus three more in the footer strip.
The image is drawn from a hand-written HTML page (`build/page.html`,
rendered to `entry.png` with headless Chromium); the program just copies it
to `/output/entry.png` after checking it is a whole PNG inside the limits.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
